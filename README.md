# Standart Development

Новый адаптивный сайт застройщика. Статический HTML/CSS/JS без внешних клиентских зависимостей.

## Запуск

`npm run dev` — http://127.0.0.1:4184

`npm run check` — проверка синтаксиса JS. `npm run build` — production-файлы в dist/.

## Формы

Демонстрационные. Данные не отправляются и не сохраняются; после проверки полей показывается «Заявка принята». CRM, Telegram-бот и email-отправка не подключены. WhatsApp использует подтверждённые номера офисов. Telegram — только иконка по просьбе заказчика.

## Материалы

source-content/ — исходные HTML и тексты, медиа и catalog.json с привязкой к URL; usage-manifest.json связывает использованные изображения с оригиналами. ANALYSIS.md — выводы анализа и ограничения. collect_source.py — сбор публичного контента. prepare.py требует Pillow и подготавливает WebP-изображения и data.json. Эти скрипты не исполняются при публикации.

Публикация: GitHub main → отдельный проект Vercel standart-development. Папка dist содержит только публичные файлы сайта.
