# Проверка и итоговые ограничения

28 октября 2026 года.

## Проверено в локальном браузере

- Ширины 320, 360, 390, 768, 1440 px: ширина документа равна ширине окна, горизонтального переполнения нет.
- Мобильное меню: открытие, переход по ссылке, закрытие.
- Фильтр Каспийска: показаны два соответствующих проекта.
- Квиз: три шага, выбор, итог предпочтений, переход к форме.
- Форма: проверка обязательных полей и телефона, состояние ожидания, сообщение «Заявка принята».
- Подробности проекта, увеличение реального изображения планировки, закрытие Escape.
- FAQ открывается.
- В консоли браузера ошибок JavaScript не обнаружено.
- Проверка синтаксиса app.js и сборка статических файлов прошли.

## Данные и интеграции

Формы работают в демонстрационном режиме. Серверной отправки, хранения, CRM и Telegram-бота нет. Имя и телефон существуют только в полях формы до её завершения/закрытия. Внешние переходы: телефон, WhatsApp, почта, Яндекс Карты, документы и каталоги исходного сайта. Telegram — некликабельная иконка по запросу пользователя.

## Уточнения после дополнительного сбора

Первоначальные HTTP 403 преодолены обычным curl, без обхода ограничений доступа: сохранены robots.txt, sitemap.xml и внутренние страницы. Итог: 77 сохранённых страниц из 82 попыток; 1000 медиа из 1004 обнаруженных ресурсов. Ошибочные ссылки и отсутствующие файлы перечислены в source-content/catalog.json. Архив исходных HTML, полных текстов и оригинальных медиа находится локально в source-content/. В GitHub размещаются код, используемые изображения, тексты и каталоги происхождения; полный тяжёлый архив оригинальных медиа остаётся в локальной папке.

На главной исходного сайта указаны 26 проектов, на /company — 24. Спорное общее число в новом сайте заменено на подтверждаемый каталог из шести проектов в продаже. Классы жилья расходятся между страницами — спорные классы не используются. Число 516 квартир повторяется у всех шести ЖК и не использовано. Даты 2002 у двух сданных домов не показаны.

Для четырёх ЖК подготовлены 35 изображений планировок, проверены визуально. Площади взяты из заголовков исходных страниц; в выбранных 3D-изображениях цифровых размеров нет. Актуальность параметров и наличия подтверждает отдел продаж. Для Wellton и Проспекта достоверно сопоставленные отдельные планировки не найдены, оставлены переходы в исходные каталоги.

Прямые видеофайлы в сохранённых страницах не обнаружены. Полнота внешних материалов и папки документов Яндекс Диска не подтверждена. Новости с датами без года и общими заголовками сохранены в архиве, но не представлены как проверенные актуальные публикации. Отзывы — выдержки с сайта компании с указанием источника; независимая проверка авторов не заявляется.

Пользователь отдельно выбрал сохранить вход через Vercel. Публикация намеренно защищена авторизацией; доступ без входа не является итоговым требованием после этого уточнения.
